  \sc{Integration Practice}\\

 Evaluate the integrals below by \textbf{first} identifying the \textbf{technique} that is appropriate. Proceed only far enough to be sure your strategy will work. Then work the problems according to \textbf{which one is hardest for you.}
\begin{enumerate}
\item $\displaystyle{\int_0^{\pi/4} \sin^2(2\theta)\: dx}$
\vfill
\item $\displaystyle{\int x \sqrt{x^2+1} \: dx}$
\vfill
\item $\displaystyle{\int \frac{\sqrt{x^2-4}}{x} \: dx}$
\vfill
\item $\displaystyle{\int_2^6  \ln (t)  \: dt}$
\vfill
\newpage
\item $\displaystyle{\int \frac{2x-3}{x^2-3x-4}  \: dx}$
\vfill
\item $\displaystyle{\int  \frac{6x}{x^2-3x-4}\: dx}$
\vfill

\item $\displaystyle{\int  \sin^6(x) \cos^3(x)\: dx}$
\vfill
\item $\displaystyle{\int_0^{\pi/2}  x\sin(7x) \: dx}$
\vfill
\end{enumerate}
